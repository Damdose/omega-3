Design system · v1 · 25 novembre 2026

Un seul système, pour vendre.

Les règles du site d'Yves Coignard, distributeur indépendant Eqology. Inspiré des mécanismes de patch.io, pensé pour le trafic Meta : un visiteur sur mobile, qui arrive d'une story, doit comprendre la promesse et trouver le bouton en trois secondes.

1 · Principes

Six règles pour le visiteur qui vient d'une pub.

  1. 01

    La même promesse que la pub

    Le titre du premier écran reprend l'accroche de la story (page partenaire : ?cible=pro, ?cible=visio).

  2. 02

    Une seule action orange

    L'orange est réservé au bouton qui fait avancer : tester, commander, être rappelé. Tout le reste est en contour.

  3. 03

    L'action dès le premier écran

    Bouton ou mini-formulaire visible sans défiler, puis une barre d'action fixe sur mobile.

  4. 04

    La preuve tout de suite

    Bande qui défile sous le titre : MSC, GOED, Superior Taste Award, Oslo. Jamais de faux avis.

  5. 05

    Le prix dans le bouton

    « Commencer par le test · 88 € » : le visiteur sait ce qui l'attend avant de cliquer.

  6. 06

    Aucune promesse de revenu

    Règle Meta et règle Heyfuture : pas de montant, pas de « liberté financière ». Toujours « distributeur indépendant Eqology ».

5 · Mécanismes

Ce qui guide le visiteur, dans assets/v2/mecanismes.js.

  • Bande qui défile

    .defile, sous le premier écran : les preuves.

  • Étapes en orbite

    MECA.orbite() : la méthode ou le circuit du partenariat, qui avance seul.

  • Onglets à progression

    MECA.onglets() : trois arguments qui changent l'image.

  • Carrousel des rayons

    MECA.carrousel() + .rail, aligné sur la colonne.

  • Phrase qui s'éclaire

    MECA.eclaire() : une conviction, lue mot à mot.

  • Barre d'action mobile

    MECA.barreMobile() : apparaît après le premier écran.

6 · Gabarits de page

Chaque page suit le même ordre.

Vitrine (accueil, boutique, fiche, test)

Image plein écran + titre géant + action orange → preuves → produits → méthode → qualité → partenariat → appel final → pied de page.

Page partenaire (pubs Meta)

Menu réduit, aucune fuite. Promesse + mini-formulaire → preuves → circuit → niveaux → revenu → exemple → profils → FAQ → formulaire → merci.html (Lead).
